# JRT ticket monitor

Легковесный монитор страницы [JRT Repertuārs](https://www.jrt.lv/repertuars/). Он оставляет только спектакли по адресу `Rīga, Lāčplēša iela 25`, считает карточку доступной, если у неё нет статуса `Izpārdots`, и отправляет письмо через Resend.

Повторные письма не приходят на каждом запуске: workflow сохраняет предыдущий набор доступных событий в GitHub Actions cache. Если билеты исчезнут, а затем появятся снова, уведомление придёт снова.

## Локальная проверка

Никакие пакеты устанавливать не нужно — достаточно Python 3.11+.

```bash
python -m unittest discover -v
python monitor.py --check-only
```

Первая команда тестирует парсер на фикстуре, в которой есть распроданный спектакль, доступный спектакль в Риге и гастрольный спектакль вне Риги. Вторая делает настоящий GET-запрос к JRT, печатает количество найденных карточек и ничего не отправляет.

## Настройка GitHub

1. Создайте репозиторий на GitHub и добавьте в него эти файлы.
2. Зарегистрируйтесь в [Resend](https://resend.com), создайте API key.
3. В репозитории откройте **Settings → Secrets and variables → Actions** и создайте два repository secrets:
   - `RESEND_API_KEY` — ключ вида `re_...`;
   - `EMAIL_TO` — ваш email. С тестовым отправителем Resend это должен быть адрес владельца аккаунта.
4. Необязательно: добавьте repository variable `EMAIL_FROM`. Без неё используется `JRT Monitor <onboarding@resend.dev>`. Свой адрес требует подтверждённого домена в Resend.
5. Откройте **Actions → Monitor JRT tickets → Run workflow**, чтобы вручную проверить страницу. Письмо будет отправлено только при наличии нового доступного билета.

После этого workflow проверяет страницу два раза в час — на 5-й и 35-й минуте. Запланированные GitHub Actions могут иногда стартовать с задержкой.

## Команды

```bash
# Только проверить живую страницу; email-переменные не нужны
python monitor.py --check-only

# Проверить локальную HTML-фикстуру
python monitor.py --check-only --html-file tests/fixtures/repertoire.html

# Реально отправить тестовое письмо
RESEND_API_KEY=re_... EMAIL_TO=you@example.com python monitor.py --force-email
```

Ключи нельзя добавлять в файлы или коммиты. Для production-запусков скрипт отправляет письмо только о новых доступных событиях; если структура страницы перестанет распознаваться, job завершится ошибкой вместо ложного уведомления.
